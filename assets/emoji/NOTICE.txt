Keynope Emoji Glyphs

The coloured block glyphs in keynope-emoji-glyphs.bin.gz are modified
derivatives of Noto Emoji artwork, Copyright 2013 Google LLC.

The source artwork was converted into Keynope's maximum-size 80 by 40
terminal-cell representation. Each stored cell contains a Unicode quadrant
mask and an RGB colour. Keynope samples this canonical representation when
rendering smaller emoji sizes. The original PNG artwork is not distributed.

The derived glyph collection is distributed under the SIL Open Font License,
Version 1.1. See OFL.txt. Keynope itself is separately licensed.

keynope-emoji-fonts.zip contains the same artwork converted losslessly into
COLRv0 colour TrueType fonts, compressed as WOFF2. The collection is named
Keynope Emoji and remains under the same SIL Open Font License 1.1. Each
quadrant is represented by a vector rectangle, retaining its original RGB
colour. Fonts are generated by tools/build_emoji_fonts.py, not from system
emoji fonts. Only the faces needed for a rendered page are included in exports.

Regional flag sources and Unicode emoji catalog data have their own notices in
NOTO-REGION-FLAGS-LICENSE.txt and UNICODE-LICENSE.txt.
